# javascript-calculator-precourse

## 기능 목록

- 첫번째 요구사항
  - 쉼표 또는 콜론 구분자를 기준으로 문자열을 분리한다
  * 분리된 문자열들을 숫자형으로 변환하여 각 숫자의 합을 반환한다
- 두번째 요구사항
  - 커스텀 구분자 위치를 포착한다 (//와 \n 사이)
  - 포착한 커스텀 구분자를 기준으로 문자열을 구분하고 숫자형으로 변환하여 각 숫자의 합을 반환한다
- 세번째 요구사항
  - 사용자가 잘못된 값을 입력하는 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션을 종료하는 예외처리를 한다
